# Maegan Elaine S. Mañez - Portfolio

Personal portfolio built with HTML5, CSS3, and vanilla JavaScript. No build step.

## Run locally
Open `frontend/index.html` with the VS Code Live Server extension, or run `cd frontend && python3 -m http.server 8000` and visit http://localhost:8000.

## Edit
- Project technologies: `frontend/index.html`, search for "EDIT".
- Certificates: the `certificates` array at the top of `frontend/script.js`.

## Deploy (Vercel)
Framework Preset: Other. Root Directory: `frontend`. Leave Build, Output, and Install commands empty.
